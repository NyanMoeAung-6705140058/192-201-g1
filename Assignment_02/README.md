# Assignment 02 — CampusWheels Vehicle-Rental Desk

This project demonstrates basic object-oriented programming in Python using:

- Classes and objects
- Encapsulation with `@property`
- Inheritance
- Polymorphism

## Files

- `rental.py` — contains `Vehicle`, `Renter`, `ElectricCar`, and `Motorbike`
- `main.py` — demonstrates that the classes work

## How to run

1. Make sure Python 3 is installed.
2. Open a terminal in the `Assignment_02` folder.
3. Run:

```bash
python main.py
```
